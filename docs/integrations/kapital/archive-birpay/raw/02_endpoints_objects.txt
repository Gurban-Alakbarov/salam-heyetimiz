## [Objects] Creates an access token to interact checkout APIs   (page 1e548b50-7ada-8155-9e8e-f1b4c24b3a2d)
=================================================
Get Bearer Token

### Body Params
| Name | Type | Description | Required? |
| client_id | string | yes |
| client_secret | string | yes |
| grant_type | string | yes |
| scope | string | yes |

### Responses
| Response Body |
| 200 | {
    "accessToken": "accessToken",
    "refreshToken": "refreshToken",
    "accessExpiresIn": 500,
    "refreshExpiresIn": 1000
} |
| 401 | {
"error": "invalid_request",
"error_description": "Missing form parameter: field_name"
} |

## Code Examples

### Request

```
curl --location --request POST 'https://base_url/api/oauth2/token' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'grant_type=client_credentials' \
--data-urlencode 'scope=email' \
--data-urlencode 'client_id=client_id' \
--data-urlencode 'client_secret=client_secret'
```

## [Objects] Used for creating payment   (page 1e548b50-7ada-8149-a800-ca9b172691cd)
=================================================
Create payment

### Body Params
| Description | Example value | Available Values | Type | Property |
| Always "amount" | "amount": {
      "value": 10.0,
      "currency": "AZN"
    } | object | amount* |
| Always true on BIRBANK and QR payment | true, false | boolean | capture* |
| Description of payment | “payment for order id 1235” | string(255) | description |
| This object is used when creating payment. | "paymentMethodData": {
    "type": "M10"
} | object | paymentMethodData |
| The field is not mandatory when confirmation type is QR. | M10, BIRBANK, BANK_CARD | enum | paymentMethodData.type |
| This object is defined when confirmation is required from customer. | "confirmation": {
    "type": "QR"
} | object | confirmation |
| This type defines what kind of confirmation will user pass. 

If confirmation is provided, type is mandatory. | QR, MOBILE, REDIRECT | confirmation.type* |
| This field is used for where acquirer will return the customer. | string(2048) | confirmation.returnUrl |
| This field used for POS terminal payments. The field is mandatory for POS terminals. | “posDetail” :{
   "merchantId": "RT123456",
   "terminalId": "RT123456"
} | object | posDetail |
| Merchant can pass specific read-only data to this field. | "metadata": {
   "orderNo": "1234",
   "instalmentTerms:": "3,6,9"
} | in order to show taksit options to customer add instalmentTerms tag to metadata | object(k, v) | metadata |

Create a refund
Payment can be refunded multiple times if refundable amount is not exceeded.

### Body Params
| Description | Example value | Available Values | Type | Property |
| Id of original payment. | 4f28fcba-81a9-4178-9276-0b38d11dc19e | string(uuid) | id* |
| Amount of refund. If not provided full refund will be performed. | bigdecimal | amount |
| If confirmation is not provided payment is refunded directly. If required confirmation should be provided. | "confirmation": {
     "type": "QR"
} | object | confirmation |
| QR, MOBILE | enum | confirmation.type |
